# MY TECH บัญชีและเอกสารออนไลน์

แอพเดียวสำหรับ Android, iPhone และคอมพิวเตอร์ ข้อมูลกิจการใช้ Cloudflare D1 ส่วนกลาง ไม่ใช้ localStorage เป็นฐานข้อมูลหลัก

## เอกสาร
ใบเสนอราคา (QT), ใบแจ้งหนี้ (INV) และใบเสร็จรับเงิน (RC) รองรับเปิดพิมพ์หรือบันทึก PDF และส่งออกภาพจากหน้าเอกสาร ใบเสร็จต้องอ้างอิงรายการรับเงินจริงของกิจการที่ยังมีผล ออกได้หนึ่งใบต่อรายการรับเงินที่ยังไม่ยกเลิก รองรับมัดจำหลายงวด ไม่เพิ่มรายรับซ้ำ ต้องยกเลิกใบเสร็จก่อนกลับรายการรับเงิน

## สิทธิ์
ตั้ง MYTECH_OWNER_EMAIL ผ่าน runtime environment ของ Sites เท่านั้น ไม่เก็บค่าจริงในซอร์ส ผู้เข้าชมคนแรกไม่มีสิทธิ์ยึดบัญชี เจ้าของเพิ่มหรือถอนอีเมลผู้แก้ไขที่เมนูตั้งค่า ทุกคำขอเขียนตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ การดูแบบสาธารณะซ่อนบัญชีส่วนตัว รายละเอียดลูกค้า เอกสาร ประวัติ และข้อมูลรอตรวจสอบ

## มือถือ
Android: เปิดลิงก์ผ่าน Chrome แล้วเลือกเพิ่มลงในหน้าจอหลักหรือติดตั้งแอพ
iPhone: เปิดลิงก์ผ่าน Safari กดแชร์ แล้วเลือกเพิ่มไปยังหน้าจอโฮม
คอมพิวเตอร์: เปิดลิงก์เดียวกันในเบราว์เซอร์ ต้องเชื่อมต่ออินเทอร์เน็ตเพื่ออ่านและบันทึกข้อมูลล่าสุด

## พัฒนาและตรวจสอบ
npm install
node --test tests/*.test.mjs
npm run build
ฐานข้อมูลใช้ schema ใน db/schema.ts และ migration ใน drizzle/ อ่าน README ของ starter สำหรับ local D1 migrations

## ข้อมูลเดิมและขอบเขต
ใช้สำเนาส่งต่อ 6 พฤศจิกายน 2569 เป็นข้อมูลตั้งต้นครั้งเดียว มีรายการรอตรวจสอบ 9 รายการ ยังไม่มีรายการรับเงินจริง
Trello ออนไลน์ยังไม่เปิดใช้งาน สำเนาการ์ดเดิมยังคงอยู่ในข้อมูลสำรอง ไฟล์แนบไม่เกิน 1 MB ต่อไฟล์ ข้อมูล state ไม่เกิน 1.5 MB กู้คืนรองรับไฟล์สำรองที่ไม่มีหลักฐานแนบเท่านั้นและไม่แทนที่หลักฐานเดิมโดยเงียบ ๆ มี snapshot ก่อนกู้คืน
ไม่มีการเชื่อมแอพธนาคารหรือนำเข้ารายการเดินบัญชีในรุ่นนี้
