# MY TECH — บัญชี สต๊อก ใบเสนอราคา และ Invoice

รุ่นใช้งานบนเครื่อง Windows นี้ เปิดแล้วใช้งานได้เลย ไม่ต้องล็อกอิน ตามที่ปิ๊กขอ

## เปิดโปรแกรม

1. ดับเบิลคลิกไฟล์ **เปิดโปรแกรม MY TECH.vbs** ในโฟลเดอร์หลัก
2. เบราว์เซอร์จะเปิดที่ **http://127.0.0.1:4317**
3. ไม่ต้องติดตั้ง Node.js เพิ่ม เพราะมีเครื่องมือแบบพกพาแนบไว้ในโฟลเดอร์ `.tools`

หากรับเป็น ZIP ต้องแตกไฟล์ทั้งหมดก่อน อย่าเปิดไฟล์ภายใน ZIP โดยตรง และอย่าย้ายเฉพาะไฟล์เปิดโปรแกรมออกจากโฟลเดอร์

## เริ่มต้นตามลำดับนี้

1. **ตั้งค่าและสำรองข้อมูล → ข้อมูลกิจการ** ใส่ชื่อ ที่อยู่ เบอร์โทร และบัญชีรับชำระสำหรับเอกสาร
2. **เพิ่มบัญชี** เช่น เงินสดกิจการ ธนาคารกิจการ หรือเงินส่วนตัวปิ๊ก
3. **ตั้งยอดยกมา** ตามเงินที่มีจริง ณ วันเริ่มใช้ระบบ ไม่ต้องเดายอดจากประวัติแชต ถ้าย้อนลงรายการก่อนวันเริ่มต้น ต้องจัดยอดยกมาให้ไม่ซ้ำกับรายการเหล่านั้น
4. **ข้อมูลรอตรวจสอบ** อ่านสรุปจากแชตทั้ง 9 รายการ ตรวจหลักฐาน แล้วจึงเพิ่มรายการจริง การกดตรวจแล้วไม่ลงบัญชีอัตโนมัติ
5. **ลูกค้าและคอร์สเรียน** เพิ่มลูกค้า → เพิ่มคอร์สและรุ่น → ลงทะเบียน → รับชำระมัดจำหรือเงินเพิ่ม
6. **รายรับ · รายจ่าย** เลือกประเภท บัญชี วันที่ จำนวน และรายละเอียด แนบหลักฐานได้หลังบันทึก
7. **สต๊อก** เพิ่มสินค้า → รับของเข้าที่เก็บ → เบิกใช้โดยระบุคอร์ส/โครงการ

## เบิกเงินซื้อของให้ไม่ซ้ำ

- ตอนปิ๊กนำเงินไปซื้อของ ให้เลือก **เบิกเงินซื้อของ** และระบุบัญชีที่เงินออก
- เมื่อมีใบเสร็จ เลือก **เคลียร์เงินเบิก** และอ้างอิงรายการเบิกเดิม ระบบนับเป็นค่าใช้จ่ายครั้งนี้โดยไม่หักเงินจากบัญชีซ้ำ
- เงินที่เหลือใช้ **คืนเงินเบิก** โดยอ้างอิงรายการเดิม
- ซื้อด้วยเงินกิจการโดยตรง เลือก **จ่ายค่าใช้จ่าย**
- หากปิ๊กออกเงินแทน ให้บันทึกแหล่งเงินตามจริงก่อน: เงินเจ้าของเติมเข้าสู่บัญชีที่ใช้จ่าย แล้วจึงบันทึกค่าใช้จ่าย รายการนี้ไม่ใช่ยอดขาย

สำหรับประวัติ Lazada ยังไม่ยืนยันยอด 15,000 บาท และยังไม่ทราบว่า 25,000 บาทรวม Lazada หรือไม่ จึงไม่ลงบัญชีให้อัตโนมัติ

## สั่งซื้อและสต๊อก

- ใบสั่งซื้อบันทึกสินค้า จำนวน และยอดรวม แต่ยังไม่เพิ่มของคงเหลือ
- กด **รับของ** เมื่อได้รับจริง รองรับรับบางส่วน และไม่ให้รับเกินใบสั่งซื้อ
- กด **จ่ายเงิน** ที่ใบสั่งซื้อ เพื่อเชื่อมยอดชำระกับยอดซื้อ ไม่ใช่การจ่ายเงินจริงผ่านธนาคาร
- ต้นทุนใช้ **ค่าเฉลี่ยถ่วงน้ำหนักแยกตามที่เก็บ** เช่น มีของ 2 ตัวต้นทุนรวม 100 บาท รับเพิ่ม 2 ตัว 140 บาท จะเป็น 4 ตัวต้นทุนรวม 240 บาท เฉลี่ยตัวละ 60 บาท
- **คืนของ** ต้องอ้างอิงใบเบิกเดิม ระบบคืนด้วยต้นทุนใบเบิกนั้น
- **โอนที่เก็บ** ย้ายทั้งจำนวนและต้นทุนโดยไม่เปลี่ยนมูลค่ารวม
- **สูตรประกอบ** เลือกสินค้าสำเร็จรูปและชิ้นส่วนต่อชุด เมื่อประกอบระบบจะตัดชิ้นส่วนและเพิ่มของสำเร็จรูปพร้อมต้นทุน ไม่มีการจ่ายเงินซ้ำ
- เครื่องมือใช้ซ้ำแยกประเภทจากวัสดุ และไม่นับในรายงานวัสดุใช้หมดตามคอร์ส
- การขายสินค้าพร้อมตัดสต๊อกในขั้นตอนเดียวและการคืนเงินลูกค้ายังไม่มีหน้าทำรายการเฉพาะ ต้องดำเนินการรับเงินและเบิกสินค้าแยก พร้อมระบุเลขอ้างอิงเดียวกัน

## ใบเสนอราคาและ Invoice

1. เพิ่มข้อมูลลูกค้าและข้อมูลกิจการให้ครบก่อน
2. เปิดเมนู **ใบเสนอราคา · Invoice** → ออกใบเสนอราคา หรือออก Invoice
3. ระบุรายการ จำนวน ราคาต่อหน่วย ส่วนลด วันเอกสาร และวันกำหนด
4. ถ้าเป็นค่าเรียน เลือกการลงทะเบียนคอร์สเดิม ยอดเอกสารต้องตรงกับราคาคอร์ส ระบบจะไม่รวมลูกหนี้ซ้ำ
5. ใบเสนอราคาแปลงเป็น Invoice ได้หนึ่งฉบับที่ยังไม่ถูกยกเลิก
6. เปิดเอกสาร → **พิมพ์ / บันทึกเป็น PDF** หรือ **ดาวน์โหลดภาพ PNG** (หากเบราว์เซอร์ไม่รองรับภาพ ให้ใช้ PDF)
7. การออก Invoice ไม่ใช่การรับเงิน ต้องกด **รับชำระ** หลังรับเงินจริง รองรับหลายงวด
8. เอกสารออกแล้วแก้ทับไม่ได้ หากผิดให้ยกเลิกพร้อมเหตุผลแล้วออกใหม่ โดยเก็บประวัติเดิม

เอกสารในรุ่นนี้เป็นเอกสารทั่วไป **ไม่ใช่ใบกำกับภาษี** และยังไม่มีการคำนวณ VAT/ภาษีหัก ณ ที่จ่ายอัตโนมัติ

## หนี้ส่วนตัว

- หนี้พี่หนุ่มประมาณ 65,000 บาทอยู่ในรายการรอตรวจสอบ
- เมื่อยืนยัน ให้เพิ่มหนี้ส่วนตัวของปิ๊ก และระบุว่าเป็นยอดประมาณหากยังไม่แน่ใจ
- การเพิ่มหนี้ไม่หักเงิน การคืนเงินต้นใช้ **คืนเงินต้นหนี้** ผ่านบัญชีส่วนตัว และแยกดอกเบี้ยเป็นอีกประเภทรายการ

## เชื่อม Trello — My Tech update

บอร์ดที่เลือก: https://trello.com/b/dfWwJHNs/my-tech-update

ในแชตมีเครื่องมือ Trello อยู่แล้ว แต่เว็บแอปต้องใช้การอนุญาตของตัวเว็บเอง โค้ดรองรับ API แล้ว ยังไม่ได้ทดสอบการเชื่อมจริงจนกว่าจะใส่ Key และ Token ของคุณ

1. ไป https://trello.com/power-ups/admin ด้วยบัญชี Trello ของคุณ
2. สร้าง Power-Up สำหรับใช้งานส่วนตัว หากยังไม่มี แล้วเปิดหน้าจัดการ **API Key** เพื่อสร้างหรือดู Key ตามขั้นตอนที่ Trello แสดง
3. ใช้ลิงก์สร้าง Token ที่หน้าจัดการ API Key ของ Trello แสดง และอ่านสิทธิ์ก่อนอนุญาต ต้องมีสิทธิ์อ่านและเขียนบอร์ดนี้สำหรับสร้าง/อัปเดตการ์ด
4. ใน MY TECH เปิด **เชื่อมต่อ Trello → ตั้งค่าการเชื่อมต่อ** ใส่ Key และ Token ในหน้าระบบโดยตรง **ไม่ต้องส่งรหัสลับมาในแชต**
5. กด **รีเฟรชจาก Trello** จนแสดงข้อมูลจริง
6. ที่ลูกค้า การลงทะเบียน สินค้า หรือใบสั่งซื้อ กด **Trello** จะวางลิงก์การ์ดเดิม หรือเลือกลิสต์แล้วสร้าง/อัปเดตการ์ดได้

การเชื่อมทำตามการกดปุ่มของคุณ ยังไม่ใช่การซิงก์เบื้องหลังตลอดเวลา ไม่ทำรายการรับเงินหรือเปลี่ยนสต๊อกจากการย้ายการ์ด หากเขียนแล้วหมดเวลา ให้รีเฟรชตรวจการ์ดก่อนลองใหม่ ระบบตรวจรหัสอ้างอิงเพื่อป้องกันซ้ำ

ลิงก์กลับระบบจาก Trello ใช้ที่อยู่บนเครื่องนี้ เปิดจากมือถือหรือคอมพิวเตอร์อื่นยังไม่ได้ รุ่นนี้ยังไม่เปิดออนไลน์

## สำรองข้อมูลและรายงาน

- **รายงาน** เลือกช่วงวันที่/คอร์ส → ส่งออก CSV (เปิดด้วย Excel ได้) หรือพิมพ์เป็น PDF
- **ตั้งค่าและสำรองข้อมูล → ดาวน์โหลดไฟล์สำรอง** เก็บไฟล์ไว้ในที่ปลอดภัย
- ไฟล์สำรองรวมรายการ หลักฐาน และประวัติ แต่ไม่รวมรหัสลับ Trello
- กู้คืนด้วยไฟล์สำรองและพิมพ์คำยืนยัน ระบบเก็บสำเนาก่อนกู้คืนไว้ใน `backups`
- ฐานข้อมูลจริงอยู่ใน `my-tech-accounting/data/mytech.sqlite` อย่าลบโฟลเดอร์ `data`
- รหัสลับ Trello ถูกเข้ารหัสด้วยกุญแจในเครื่อง สำรองทั้ง `data` ขณะปิดโปรแกรมหากต้องการย้ายรหัสลับไปเครื่องใหม่
- รายงานรุ่นนี้ยังไม่ใช่งบกำไรตามเกณฑ์คงค้าง ตัวเลขคำนวณจากรายการที่บันทึก และการกลับรายการทำให้ยอดรายงานปรับตามรายการที่ยังมีผล

## ขอบเขตที่สำคัญ

- รุ่นนี้ไม่มีล็อกอิน ทุกคนที่ใช้คอมพิวเตอร์เครื่องนี้และเปิดเว็บนี้ทำรายการในฐานะเจ้าของได้ ตามที่ปิ๊กกำหนด
- เปิดบริการเฉพาะ 127.0.0.1 ไม่เปิดให้เครื่องอื่นในเครือข่าย ไม่มีการเผยแพร่ข้อมูลขึ้นอินเทอร์เน็ต
- การบันทึกจ่ายเงินเป็นการลงข้อมูลบัญชี ไม่สั่งโอนเงินหรือจ่ายเงินให้ใคร
- สำรองข้อมูล JSON จำกัดขนาดกู้คืน 10 MB ในรุ่นแรก หากไฟล์หลักฐานทำให้เกินนี้ ให้เก็บสำรองโฟลเดอร์ data ขณะปิดระบบแทน
- หน่วยเงินเป็นสตางค์ จำนวนสินค้ารองรับทศนิยม 3 ตำแหน่ง

## ผลตรวจรุ่นเริ่มต้น

ทดสอบอัตโนมัติแยกจากฐานข้อมูลจริง: ความแม่นยำสตางค์ มัดจำหลายงวด ผู้เรียนร่วมคอร์ส เงินเบิก/ใบเสร็จ/เงินคืน การรับของบางส่วน คืนและโอนสินค้า การประกอบแบบทำสำเร็จพร้อมกัน การแยกหนี้ส่วนตัว การป้องกันคำขอซ้ำ การบันทึกถาวรและกู้คืน ใบเสนอราคาแปลง Invoice และลูกหนี้ไม่ซ้ำ

Trello จริงยังรอ Key/Token ไม่ได้อ้างว่าทดสอบสำเร็จแล้ว ระบบยังไม่เผยแพร่ออนไลน์ตามคำขอให้ตรวจหน้าจอก่อน
