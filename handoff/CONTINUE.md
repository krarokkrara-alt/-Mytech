# ส่งต่องาน MY TECH — 6 พฤศจิกายน 2569

เจ้าของกิจการ สุปัญญา (ปิ๊ก) เครื่องเดิมเป็นเครื่องร้านเกม ต้องย้ายข้อมูลออกไปเก็บเอง ไม่ใช้เครื่องร้านเกมเป็นที่เก็บหลัก

## วิธีเปิดบนเครื่อง Windows ส่วนตัว
1. ดาวน์โหลดและแตกไฟล์ชุดย้ายงานนี้
2. แตก MYTECH-โปรแกรมพร้อมภาพสรุป.zip อีกครั้ง จะได้โฟลเดอร์ MYTECH-portable
3. ดับเบิลคลิก เปิดโปรแกรม MY TECH.vbs ในโฟลเดอร์นั้น ระบบเปิด http://127.0.0.1:4317 ไม่ต้องล็อกอิน
4. ไป ตั้งค่าและสำรองข้อมูล → กู้คืนจากไฟล์สำรอง → เลือก MYTECH-backup-ล่าสุด.json จากชุดย้ายงาน → พิมพ์ กู้คืนข้อมูล → ยืนยัน
5. ตรวจหน้าภาพรวม ข้อมูลรอตรวจสอบ ลูกค้า รายการเงิน และเอกสาร
6. หากต้องเชื่อม Trello ต้องใส่ API Key/Token ใหม่ในหน้าระบบเอง ชุดนี้ไม่รวมรหัสลับใด ๆ

Google Drive เป็นที่เก็บไฟล์สำรองในขั้นตอนนี้ ไม่ใช่ฐานข้อมูลที่เว็บซิงก์อัตโนมัติ หากลงรายการเพิ่มต้องดาวน์โหลดไฟล์สำรองใหม่และเก็บใน Drive อีกรอบ

## พรอมต์สำหรับแชตหรือ AI ที่จะทำต่อ
ช่วยทำต่อโปรแกรม MY TECH จากซอร์สใน ZIP นี้และฐานข้อมูลสำรอง JSON ที่แนบ ห้ามเริ่มทำระบบใหม่ทับงานเดิม ก่อนแก้ให้อ่านคู่มือและตรวจโครงสร้างจริง

โปรแกรมเป็น Node.js 24.11.1 แบบไม่ต้องติดตั้ง มี node.exe ใน .tools ใช้ SQLite ใน my-tech-accounting/data/mytech.sqlite และหน้า HTML/CSS/JS ไม่ใช้แพ็กเกจ npm เพิ่ม ระบบผูกเฉพาะ 127.0.0.1:4317

มีรายรับคอร์ส มัดจำหลายงวด รายจ่าย เงินเบิกและเคลียร์ใบเสร็จ สต๊อกรับ/เบิก/คืน/โอน การรับของบางส่วน สูตรประกอบ Simulator หนี้ส่วนตัว ใบเสนอราคา และ Invoice พร้อมพิมพ์ PDF/ส่งออกภาพ CSV และสำรอง/กู้คืน JSON

ข้อกำหนดล่าสุด: เปิดใช้โดยไม่ต้องล็อกอิน เพราะผู้ใช้ขอ แต่ต้องออกแบบการเก็บข้อมูลให้เหมาะกับการย้ายออกจากเครื่องร้านเกม ห้ามเปิดโปรแกรมรุ่นไม่มีล็อกอินสู่อินเทอร์เน็ตโดยตรง หากจะทำออนไลน์ต้องเสนอสิทธิ์เข้าถึงและให้ผู้ใช้ตรวจรับก่อน

## ข้อมูลการเงินที่ผู้ใช้แจ้ง
- มีผู้มาเรียนคอร์ส 7,500 บาททั้งหมด 6 คน โดยหนึ่งคนเป็นผู้เรียนจากคอร์ส 30,000 บาทที่มาร่วมเรียน ต้องจับคู่กับรายชื่อเดิมก่อนสรุปยอดรับรวม
- ปราเมทย์ เพ็ชรัตน์ ลงคอร์ส 30,000 บาท รับมัดจำแล้ว 10,000 บาท เหลือ 20,000 บาท ต้องตรวจการจับคู่รายชื่อ
- เดิมแจ้งหมายเลข 4–6 จ่ายครบ หมายเลข 5–6 เป็นเงินสด แต่ยอดรายคนและความซ้ำกับคอร์ส 30,000 บาทยังต้องตรวจ
- ปิ๊กนำเงินสดจากผู้เรียนหมายเลข 5–6 ไปซื้อของ Lazada ให้บันทึกเป็นเงินเบิกซื้อของ ยังไม่ยืนยันยอด 15,000 บาทจากการคาดคะเน
- ซื้ออุปกรณ์อิเล็กทรอนิกส์เพิ่ม 25,000 บาท ยังไม่ทราบว่ารวม Lazada หรือเป็นคนละรายการ
- หนี้ส่วนตัวสุปัญญา (ปิ๊ก) ติดพี่หนุ่มประมาณ 65,000 บาท แยกจากกิจการ
- อุปกรณ์ทำคอร์สยอดสรุปเดิม 300 บาท วันที่ 11 กันยายน 2569 แต่ราคาย่อยรวม 301 บาท ต้องตรวจใบเสร็จ
- วัสดุปรับปรุงและบำรุงรักษา 3,022.59 บาท ยังไม่ยืนยันว่าเกี่ยวกับคอร์ส
- หมายเลข 1 ยังไม่พบยืนยันจ่าย หมายเลข 2–3 คนหนึ่งมาแต่ไม่จ่าย อีกคนไม่มา ต้องเช็กว่าใคร
- ห้ามใช้ยอดรับรวม 32,500 บาทจากสรุปเก่าเป็นยอดยืนยัน

## หลักป้องกันการนับซ้ำ
เงินเบิกไม่ใช่ค่าใช้จ่ายจนเคลียร์ใบเสร็จ การเคลียร์ไม่หักเงินซ้ำ ใบเสนอราคาไม่สร้างรายรับ Invoice ไม่ถือว่ารับเงิน ลูกหนี้ Invoice ของคอร์สต้องอ้างอิงการลงทะเบียนเดิมไม่รวมซ้ำ การย้ายการ์ด Trello ไม่รับ/จ่ายเงินหรือตัดสต๊อกอัตโนมัติ

## สิ่งที่ตรวจแล้วและข้อจำกัด
ทดสอบอัตโนมัติผ่าน 10 กรณี ดู tests/model.test.mjs และ tests/server.test.mjs ตรวจหน้าแดชบอร์ดเปิดได้ไม่ต้องล็อกอิน ข้อมูลจากแชตนำเข้าเป็น pending 9 รายการ ไม่เพิ่มเงินหรือสต๊อกจริง
ต้นทุนเฉลี่ยถ่วงน้ำหนักแยกที่เก็บ เงินเป็นสตางค์ ปริมาณสินค้าทศนิยม 3 ตำแหน่ง การกลับรายการปรับรายงานตามรายการที่ยังมีผล ยังไม่ใช่งบบัญชีตามเกณฑ์คงค้าง เอกสารทั่วไปไม่ใช่ใบกำกับภาษี ยังไม่มี VAT/หัก ณ ที่จ่ายอัตโนมัติ ยังไม่มีซิงก์ Trello เบื้องหลังตลอดเวลา
JSON กู้คืนจำกัด 10 MB รวมไฟล์หลักฐาน ก่อนใช้งานจริงระยะยาวควรพัฒนาขนาดสำรอง/กู้คืน และทดสอบการเชื่อม Trello ซ้ำ/เขียนจริงตามรายการที่ผู้ใช้อนุญาต

## สิ่งที่ต้องทำต่อ
1. ย้ายและกู้คืนบนเครื่องส่วนตัว หรือออกแบบระบบออนไลน์ที่มีสิทธิ์เข้าถึงเหมาะสม
2. ให้ผู้ใช้ตรวจข้อมูลรอตรวจสอบและแหล่งเงินจริงก่อนลงบัญชีจริง
3. ทดสอบการออกเอกสาร/PNG/PDF และการสร้างหรืออัปเดต Trello ในเครื่องปลายทาง
4. เมื่อยืนยันว่าข้อมูลย้ายสำเร็จแล้ว ค่อยขอผู้ใช้ยืนยันการลบข้อมูลและรหัสลับจากเครื่องร้านเกม ห้ามลบก่อนมีสำเนาตรวจสอบได้
